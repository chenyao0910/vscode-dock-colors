Dock Colors GitHub

A VS Code extension for macOS

A new look for your Dock.

Change the color of your VS Code app icon. Pick from 28 built-in variants or bring an image of your own.

Get it on Marketplace Download VSIX

Browse the palette

Make it yours

Open Dock Colors: Preview App Icons from the Command Palette and click the icon you want. Use Restart VS Code if the Dock still shows the previous icon.

Bring your own icon

Set Custom Icon Path to a local PNG or ICNS file, then select Custom as your app icon.

For Visual Studio Code Stable on Apple Silicon and Intel Macs.
